# Security policy

Do not include credentials, device identifiers, enrollment certificates or exploit details
in a public issue. Contact a maintainer listed in [CODEOWNERS](.github/CODEOWNERS) to arrange
a private reporting channel. If no private contact is available, open an issue requesting a
security contact without describing the vulnerability.

A report should include the affected commit or version, relevant configuration, reproduction
steps and expected impact. Share sensitive reproduction material only through the agreed
private channel.

No release has been made yet; there are no supported versions. The threat model and the
operational security guides arrive with Phase 15 of the [implementation plan](docs/implementation_plan.md).
